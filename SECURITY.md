# Security Policy

## Supported Versions

Security fixes are provided for the latest stable release of the current major version only.

| Version                  | Supported          |
| ------------------------ | ------------------ |
| 3.x (latest)             | :white_check_mark: |
| 2.x and older            | :x:                |
| Pre-releases (`-beta.*`) | :x:                |

Versions 1.x and 2.x are no longer supported. Please upgrade to the latest stable `dgt.power` release.
Pre-release versions are for evaluation only and are not covered by this policy.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions or pull requests.**

Use GitHub's private vulnerability reporting instead:

1. Go to the [Security tab](https://github.com/DIGITALLNature/DigitallPower/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the issue and submit the report.

It helps us if you include:

- the affected version(s) of `dgt.power`, and your OS and .NET version
- a description of the vulnerability and its potential impact
- steps to reproduce, or a proof of concept
- any suggested mitigation or fix

## What to Expect

This is a small team, so we handle reports on a best-effort basis:

- We will get back to you as soon as we can to confirm that we received your report.
- We will look into the issue and keep you posted on our findings.
- For confirmed vulnerabilities in a supported version, we aim to provide a fix and publish a
  [GitHub Security Advisory](https://github.com/DIGITALLNature/DigitallPower/security/advisories).
  We are happy to credit you, unless you prefer to remain anonymous.

Please give us a reasonable amount of time to release a fix before any public disclosure.

## Scope

In scope: the `dgt.power` dotnet tool (`dgtp`) and the code and templates generated by it, for example credential or token handling, stored connection profiles, and code generation output.

Out of scope:

- vulnerabilities in unsupported versions (see above)
- vulnerabilities in third-party dependencies that are not exploitable through `dgt.power` (please report those upstream)
- issues in Microsoft Power Platform, Dataverse or the Power Platform CLI (PAC) themselves; report those to the [Microsoft Security Response Center](https://msrc.microsoft.com/)
